# 무무베딩 수량관리 웹앱

직원 가입→사업주 승인→주소 사진 OCR→수량 등록→수정 즉시 반영(수정 전후 이력 보존)→사업주 통계/엑셀.

## 실행
Node.js 20 이상에서:
1. `npm install`
2. Supabase 프로젝트를 생성하고 `supabase.sql`을 SQL Editor에서 실행
3. `.env`에 제공하신 Supabase Project URL과 **공개 publishable 키**가 이미 입력되어 있습니다.
4. `npm run dev`

## 최초 사업주 설정
1. 앱 회원가입으로 사업주 이메일 계정 생성 (Supabase Email 인증 설정에 따라 이메일 확인 필요)
2. `supabase.sql` 마지막의 주석 처리된 UPDATE문에서 이메일을 변경하여 실행
3. 다시 로그인하면 사업주 대시보드가 열림
4. 이후 직원은 앱에서 가입하고, 사업주가 직원관리에서 승인

## 배포
Vercel/Netlify에서 저장소 연결 후 빌드 명령 `npm run build`, 출력 폴더 `dist` 설정.
`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`를 환경변수로 설정.
`service_role` 키는 절대 웹앱에 넣지 마세요.

## 동작 기준
- 오전 00:00–11:59, 오후 12:00–23:59 (한국 시간)
- 활동 인원: 해당 기간에 1건 이상 등록한 고유 직원 수
- 직원의 수정은 승인 없이 즉시 반영되며 원본 수량은 수정 이력에 남음
- 주소 OCR은 사진 속 텍스트 인식으로, 촬영 내용에 주소가 없으면 자동 인식할 수 없음. 직원 확인/수정 필수.
- 사진은 브라우저에서 처리하고 서버에 저장하지 않음.
- 직원은 본인 기록만 조회/수정, 사업주는 전체 조회 가능.
- 계정 정지는 DB 작업 권한을 제한하지만 기존 인증 세션 자체를 강제 로그아웃하지는 않음.
- 공개 서비스 전 실제 Supabase 계정으로 권한/시간대 테스트 권장.
